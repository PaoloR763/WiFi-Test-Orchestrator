# WTO contracts 1.0.0

- JSON Schema: Draft 2020-12.
- OpenAPI: 3.1.0.
- Agent protocol: 1.0.0.
- Capability catalogue: 1.0.0.

Schema documents are immutable after publication. `schema_version` is a
three-component SemVer string. Unknown schema, protocol and vocabulary versions
are rejected; they are never interpreted as unsupported capabilities.

Golden examples are indexed by `examples/manifest.json`. Files under
`prompts/examples/` are historical and non-normative.
