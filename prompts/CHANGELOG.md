# Changelog del paquete de prompts

## 2.0 - 2026-07-11

- Motor de tráfico desacoplado de iperf3.
- Prompts separados para arquitectura de tráfico, proveedor iperf3, tráfico HTTP/native y latency-under-load.
- Flent y Tcpreplay incorporados como extensiones especializadas y no como dependencias obligatorias.
- Nuevo modelo de perfiles de tráfico y pool de servidores de prueba.
- Guía de SDK de plugins, versionado, migraciones y compatibilidad hacia atrás.
- Mayor detalle de time synchronization, comparabilidad de resultados, seguridad, cuotas y runbooks.
- Fases ampliadas de 20 a 26.
- Documentación y troubleshooting como entregable de primera clase.

## 1.1 - 2026-07-11

- Agentes Windows, Linux, Android e iOS.
- Servidor Windows-first portable.
- Modelo capability-driven y restricciones mobile.
