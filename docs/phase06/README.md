# Fase 06: adapter Windows

Fase 06 implementa el adapter Windows 10/11 sobre el núcleo desktop de Fase 05. No agrega
endpoints, schemas ni capability IDs. Inventario, scan y administración local permanecen en el
agente; task delivery, probes, tráfico, captura productiva e ingestión de telemetría siguen
diferidos.
